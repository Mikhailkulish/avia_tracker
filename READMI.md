# Avia_Tracker
Приложение представляет собой трекер поиска самолетов над указанными пользователем странами, с созданием баз данных Postgres для хранения полученной в запросе информации.
## Установка и использование
Чтобы установить и запустить проект, нужно выполнить следующие действия:
* клонировать репозиторий, использовав ссылку с аккаунта GitHub;
* установить poetry командой pip install poetry;
* установить зависимости, введя poetry install;
* активировать виртуальное окружение командой poetry init;
* запустить приложение с помощью python main.py, следовать пунктам меню.
Также для работы сервиса потребуется установка приложения PostgreSQL.
### Доступный функционал
Рабочий код проекта реализован посредством следующих блоков:
* APIAdapter - класс поиска самолетов по странам, дочерний базовому абстрактному классу BaseAPIAdapter;
* модуля fill_db.py - создает и заполняет базы данных; при каждом новом запросе информация обновляется, с удалением внесенных ранее сведений, но сохранением структуры таблиц;
* модуля db_manager.py - содержит класс DBManager для управления запросами к базе данных.
В классе APIAdapter, наследующем от BaseAPIAdapter, реализованы и переопределены следующие методы:
* __init__ - инициализация атрибутов класса;
* get_aeroplanes - поиск самолетов по странам.
В модуле fill_db.py реализованы следующие функции:
* get_connection - создает соединение с базой данных;
* create_db - создает базы данных и таблицы;
* clear_data - очищает все данные из таблиц, удаляя информацию, но сохраняя структуру;
* add_country - добавляет страну в таблицу, если ее нет;
* save_aircraft - сохраняет информацию о самолете;
* save_track - сохраняет трек, с защитой от дублей;
* get_country_id - получает ID страны;
* get_existing_aircraft_in_country - получает список ICAO, уже сохраненных в этой стране;
* fill_country - заполняет одну страну;
* get_countries_from_user - просит пользователя ввести страны;
* fill_all_countries - заполняет все введенные страны, с защитой от дублей;
* delete_all_aircraft - удаление всех сохраненных данных о самолетах;
* update_aircraft - обновление информации о самолете;
* count_aircraft - возвращение количества сохраненных самолетов;
* get_statistics - получение статистики по сохраненным данным;
В классе DBManager реализованы следующие методы:
* __init__ - инициализирует объект класса;
* _connect - устанавливает соединение с базой данных;
* close - закрывает соединение с базой данных;
* get_countries_and_aeroplanes_count - получает список всех стран и количество самолетов;
* get_all_aeroplanes - получает список всех воздушных судов с данными;
* get_avg_speed - получает среднюю скорость по всем самолетам;
* get_aeroplanes_with_higher_speed - получает список всех самолетов, у которых скорость выше средней;
* get_aeroplanes_with_keyword - получает список всех самолетов, в позывном которых содержатся переданные символы;
* get_aeroplanes_by_country - получает список самолетов для конкретной страны;
* get_statistics_summary - получает сводную статистику по базе данных;
* print_countries_and_aeroplanes_count - выводит список стран с количеством самолетов в удобном формате;
* print_all_aeroplanes - выводит список всех самолетов (первые N);
* print_aeroplanes_with_keyword - выводит список всех самолетов с ключевым словом в позывном;
* print_avg_speed - выводит среднюю скорость;
* print_aeroplanes_with_higher_speed - выводит список самолетов со скоростью выше средней. 
Реализовано логирование, для чего создан отдельный класс LoggerManager. Предусмотрено сохранение логов отдельными файлами в директории logs в корневом каталоге проекта.
Перечисленные классы расположены в директории src в корневом каталоге проекта.
Разработаны тесты для проверки правильности работы функционала с использованием фреймворка Pytest, для полного покрытия кода модулей. Тесты расположены в директории Tests в корневом каталоге проекта. Фикстуры вынесены в модуль conftest.py.
Работа над проектом завершена.
## Пример использования
После запуска приложения пользователю будет предложено меню с указанием доступных опций. Можно выбрать необходимую позицию, после чего следовать указаниям в интерфейсе программы. При вводе некорректных данных приложение завершает работу.
